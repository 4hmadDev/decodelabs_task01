# Data Cleaning and Preparation

This project was completed as part of my internship at Decode Labs.

## Project Goal

The goal of this project was to clean and prepare a raw dataset for analysis using Python and Pandas.

## Tasks Performed

- Checked the dataset for missing values
- Handled null values
- Checked and removed duplicate records
- Corrected data types
- Converted the Date column to datetime format
- Verified the cleaned dataset
- Exported the cleaned data to a CSV file

## Tools Used

- Python
- Pandas
- Google Colab

## Dataset

The dataset contains 1,200 rows and 14 columns related to customer orders.

Some of the columns include:

- OrderID
- Date
- CustomerID
- Product
- Quantity
- UnitPrice
- PaymentMethod
- OrderStatus
- CouponCode
- TotalPrice

## Final Result

After cleaning:

- Missing values were handled
- Duplicate records were checked
- Data types were corrected
- Final dataset shape: 1200 rows × 14 columns

The cleaned dataset was exported as `cleaned_dataset.csv`.
